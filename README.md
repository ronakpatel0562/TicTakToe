#### 4. Roulette Royale (Live European 37-Pocket Wheel — Multiplayer)
* **Mechanics**: Authentic single-zero European Roulette featuring 37 pockets (`0` green, `1-36` alternating red/black).
* **Betting Board**:
  * **Direct Number (Straight Up)**: High-stakes 36x payout on any exact pocket `0` through `36`.
  * **Outside Bets**: Red/Black (2x), Even/Odd (2x), Low 1-18/High 19-36 (2x), and Dozens (1st, 2nd, 3rd 12 at 3x).
* **Authentic 0-Loss House Edge**: When the winning pocket is Green `0`, all outside bets lose 100% ($0 return), creating genuine risk.
* **Live Multiplayer Experience**: 25s betting window with 5-second bet-lock overlay, animated 37-pocket rotating canvas wheel with deceleration physics, ball deflection, and real-time community betting feed with dynamic bot wagers.

#### 5. Plinko Multiplier Drop (With 0x Loss Zones)
* **Mechanics**: Drop pinballs down an 8-row pyramid of bouncing pegs with real-time elasticity physics into bottom multiplier buckets.
* **Authentic 0x Total Loss Options**: Center buckets feature real `0x` multipliers to ensure genuine loss conditions:
  * *Low Risk*: `[5.6x, 2.0x, 1.2x, 0.5x, 0x, 0.5x, 1.2x, 2.0x, 5.6x]` (1 zero-loss bucket)
  * *Medium Risk*: `[13x, 3.0x, 1.2x, 0x, 0x, 0x, 1.2x, 3.0x, 13x]` (3 zero-loss buckets)
  * *High Risk*: `[29x, 4.0x, 0x, 0x, 0x, 0x, 0x, 4.0x, 29x]` (5 zero-loss buckets — high volatility!)
* **Loss Mechanics**: Hitting `0x` results in $0 return (complete loss of wager), triggerable loss sound, and warning visual cues.
* **Controls**: Multi-ball drop triggers, chip selectors (`$5`, `$10`, `$25`, `$50`), and wallet integration.
